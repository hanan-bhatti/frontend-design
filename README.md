# Frontend Design Master - Skill Repository

A comprehensive collection of 30+ distinctive aesthetic themes and a production-grade AI skill for frontend design orchestration.

## 📦 What's Inside

- **`skill/`**: The core **Frontend Design Master** skill. It combines the intelligence of `ui-ux-pro-max` with deep UX psychology and curated themes.
- **`data/`**: 30+ XML export files containing detailed prompts for various design aesthetics (Cyberpunk, Neo-Brutalism, SaaS, etc.).
- **`references/`**: Comprehensive guides on animation, color systems, typography, and UX psychology.
- **`scripts/`**: Python utilities for design system searching and UX auditing.

## 🚀 How to Use the Skill

This repository is designed to be used with **Claude Code**, **GitHub Copilot CLI**, or **Codex**.

### Installation (Claude Code)
Clone this repo and link the skill to your local Claude configuration:
```bash
ln -sf $(pwd)/skill ~/.claude/skills/frontend-design-master
```

### Usage Examples
Trigger the design intelligence by describing your intent:
- "Create a landing page in the **Neo-Brutalism** style."
- "Apply the **Swiss Minimalist** theme to this dashboard."
- "Audit my UI components for **UX Psychology** compliance."
